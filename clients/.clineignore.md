# .clineignore — clients/ context boundary (Agent 02)

Keep reads inside `clients/` only, and only the files that affect the
HighLevel Marketplace INSTALL / OAuth callback change.

## Read (allowed)
- `cmd/grpc-service/main.go` — service wiring (entry point; how repos/services are injected)
- `config/model.go` — env bindings used by OAuth/webhook
- `oauth/service.go`, `oauth/errors.go` — callback/token-exchange logic
- `webhooks/service.go` — ProcessWebhook, INSTALL resolution, event idempotency
- `providers/provider.go`, `providers/webhook.go`, `providers/registry.go`,
  `providers/highlevel.go`, `providers/highlevel_webhook.go`
- `service/integrations_service.go` (existing InstallIntegration conventions),
  `service/clients_service.go`, `service/platforms_service.go`
- `http/oauth_handler.go`, `http/webhook_handler.go`
- `db/migrations/000001_init_schema.{up,down}.sql`, `000002_oauth_states.*`,
  `000004_payment_provider_configs.*`
- `db/query/clients.sql`, `integrations.sql`, `platforms.sql`,
  `oauth_states.sql`, `oauth_tokens.sql`, `payment_provider_configs.sql`
- `db/repo/client_repo.go`, `integration_repo.go`, `platform_repo.go`,
  `oauth_state_repo.go`, `oauth_token_repo.go`, `payment_provider_config_repo.go`,
  `errors.go`
- `db/sqlc/*.go` — generated signatures only (models, querier) to confirm field names
- Existing `*_test.go` for the above ONLY to match test conventions / debug failures

## Ignore / do not open
- Everything outside `clients/` (transactions/, deposits/, payments (root pkg under clients is OK), pawaPay, etc.)
- `clients/payments/`, `clients/health/` — not in the INSTALL/OAuth call path
- `cmd/grpc-service/gateway_test.go`, `runtime_test.go` unless a directly affected failure
- Generated / dependency trees: `grpc/go/`, `third_party/`, `vendor/`, `node_modules/`, `.git/`, build output
- `db/sqlc/` internals (only signature references)
- `.git/`, any `.env`, secrets
- Non-HighLevel provider files not in the call path

Note: `payments/{service,errors}.go` and `providers/highlevel_payment_provider.go`
are for the GHL Custom Payment Provider endpoints, NOT the Marketplace
INSTALL/OAuth callback. Read only if the checkpoint marks them affected.
