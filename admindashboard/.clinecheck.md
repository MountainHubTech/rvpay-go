Lightweight verification checklist for the entire Dockerization sequence. Agents may mark only checks they actually verified.

- [ ] Application configuration valid (Agent 02)

- [ ] Production container starts (Agent 03/06)
- [ ] Runtime environment handling verified (Agent 04)
